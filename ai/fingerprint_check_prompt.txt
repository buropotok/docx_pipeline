ПРОВЕРКА FINGERPRINT ДОКУМЕНТА (ВТОРОЙ AI - ВАЛИДАТОР)
================================================================

ТЕБЕ ПЕРЕДАНЫ:
1. ИСХОДНЫЙ JSON: donor.optimized.json (оригинальный документ с run_id)
2. FINGERPRINT: результат работы первого AI (прилагается ниже)

ЗАДАЧА:
Проверь fingerprint на соответствие правилам и укажи на все ошибки.

ЧАСТЬ 1: ПРАВИЛА КЛАССИФИКАЦИИ (ЛОГИЧЕСКИЙ ТЕСТ)

Для каждого сегмента нужно задать три вопроса:

ВОПРОС A: Может ли измениться этот текст ПОЛНОСТЬЮ при смене лица/акта при том же учреждении и бланке?
   (например, ФИО, даты, номера, индивидуальные примечания)
   Варианты ответа: ДА / НЕТ

ВОПРОС B: Может ли измениться этот текст ПОЛНОСТЬЮ при смене учреждения при том же типе бланка?
   (например, название органа, адрес, контакты, реквизиты, текст печати)
   Варианты ответа: ДА / НЕТ

ВОПРОС C: Является ли этот текст универсальной частью структуры формы?
   (метки полей, заголовки, служебные формулировки, пояснения)
   Варианты ответа: ДА / НЕТ / ЧАСТИЧНО

ПРАВИЛА КЛАССИФИКАЦИИ:

| Вопрос A | Вопрос B | Вопрос C | КЛАСС | ДЕЙСТВИЕ |
|----------|----------|----------|-------|----------|
| НЕТ | НЕТ | ДА | template_static | сегмент корректен |
| ДА | любой | НЕТ | document_dynamic | сегмент корректен |
| любой | ДА | НЕТ | issuer_profile | сегмент корректен |
| НЕТ | НЕТ | ЧАСТИЧНО | требует РАЗДЕЛЕНИЯ | сегмент должен быть разбит на части |

Если несколько "да" приоритет: document_dynamic > issuer_profile > template_static.
Если не хватает данных → ambiguous.

ЧАСТЬ 2: ЧТО ПРОВЕРЯТЬ

1. РАЗДЕЛЕНИЕ МЕТОК И ЗНАЧЕНИЙ:
   - Найди все сегменты с комбинацией НЕТ + НЕТ + ЧАСТИЧНО
   - Они ДОЛЖНЫ быть разделены на несколько сегментов
   - Особое внимание удели: "Исп:", "Тел.:", "e-mail:", "№", "от", "г.", "Город (селение):", "Республика:"

2. КЛАССИФИКАЦИЯ ПО ЛОГИЧЕСКОМУ ТЕСТУ:
   - Для каждого сегмента мысленно ответь на три вопроса
   - Проверь, соответствует ли class полученному результату
   - Убедись, что нет противоречий

3. КОРРЕКТНОСТЬ ID:
   - Все ID имеют формат run_N или run_N.M (где N, M - целые числа)
   - Нет пропусков или дубликатов
   - При разделении run_N должен стать run_N.1, run_N.2 и т.д.

4. ПОЛНОТА ПОКРЫТИЯ:
   - Каждый абзац с видимым текстом присутствует в fingerprint
   - Ни один символ исходного текста не потерян
   - Количество элементов fingerprint соответствует количеству абзацев с текстом

5. SOURCES:
   - Диапазоны start/end корректны (не выходят за длину текста исходного run)
   - При объединении нескольких run'ов порядок sources правильный (хронологический)
   - Сумма длин текста всех сегментов в абзаце равна длине исходного текста абзаца

ЧАСТЬ 3: ФОРМАТ ОТВЕТА

Если ошибок НЕТ: "Валидация пройдена успешно"

Если ошибки ЕСТЬ: верни ИСПРАВЛЕННУЮ ВЕРСИЮ fingerprint (полностью) и краткий список того, что было исправлено.
